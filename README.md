Tech+Trust Ltd. - Website

This is the official website for Tech+Trust Ltd., a company providing premium incubation and poultry farming solutions in Rwanda. The website showcases our range of high-efficiency egg incubators, poultry services, and our mission to empower local farmers through technology and support.

Features
Modern & Responsive Design: Built with HTML5, CSS3, and vanilla JavaScript for a fast and seamless experience on all devices.

Interactive Elements: Features smooth scrolling animations, dynamic tabs, and an engaging user interface.

Contact Integration: Includes a functional contact form and a direct link to WhatsApp for easy communication.

SEO Optimized: Includes meta tags and structured data (JSON-LD) for better search engine visibility.

Built With

HTML5 - For semantic markup and structure.

CSS3 - For styling, including custom properties (CSS variables), Flexbox, and Grid.

JavaScript (Vanilla) - For interactive functionality like the mobile menu, smooth scrolling, and animations.

Font Awesome - For icons.

Google Fonts - For typography (Montserrat & Poppins).
